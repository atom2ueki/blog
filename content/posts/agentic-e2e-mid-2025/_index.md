## Editorial intent

The series is written as a retrospective on the two-month period around mid-2025 when I was exploring agentic E2E automation stacks:

- LangGraph with DOM-only browser control
- Playwright MCP and Browser Use
- YOLO plus coordinates plus UI understanding experiments
- D2Snap and DOM downsampling
- Chrome DevTools MCP
- multimodal computer-use models
- multi-agent orchestration with a modified Deep Agents approach
- the current direction: agent-browser plus multimodal plus Playwright Test Agents
